# MoMo Insights

Privacy-first mobile money statement analysis — built entirely in the browser.

See **[momo-insights/README.md](./momo-insights/README.md)** for setup, usage, and Vercel deployment instructions.

## Quick Start

```bash
cd momo-insights
npm install
npm run dev
```

## Deploy to Vercel

Set the **Root Directory** to `momo-insights` when importing the repository.
